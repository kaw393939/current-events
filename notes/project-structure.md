# Project Structure & Technologies

## What Each File Does

| File or folder | Purpose |
| --- | --- |
| `README.md` | The repository front door: it explains the project and links to the site, articles, and class notes. |
| `index.html` | The homepage visitors see on GitHub Pages. |
| `notes.html` | A student-facing guide page with links and a project checklist. |
| `styles.css` | Controls typography, spacing, color, layout, and mobile behavior. |
| `global_events.md` | The Global Events article and its source links. |
| `ai_events.md` | The AI Events article and its source links. |
| `images/` | Project images used by the articles and website. |
| `.github/workflows/deploy-pages.yml` | Tells GitHub Actions how to publish the static site. |

## Technologies Used

- **HTML** gives the webpage structure: headings, navigation, sections, links, images, and article text.
- **CSS** creates the Swiss-inspired design system: grid-based layouts, bold type, red and blue accents, borders, and responsive spacing.
- **Markdown** keeps article and class-note pages easy to write and review on GitHub.
- **Mermaid** creates text-based diagrams directly inside Markdown.
- **Git and GitHub** track changes, store the repository, and make collaboration possible.
- **GitHub Actions and GitHub Pages** publish the static website when changes are pushed to `main`.

## Design Choices

Swiss design is not just “large text and grids.” It uses a clear hierarchy, a limited color palette, deliberate alignment, and enough empty space for the content to breathe. This site uses one dark ink color, one electric blue, one signal red, a warm paper background, and a strict border system.
