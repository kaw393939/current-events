# GitHub Pages

GitHub Pages turns your repo into a website.

1. Push your project to GitHub.
2. Open **Settings → Pages**.
3. Choose **GitHub Actions**.
4. Wait for the workflow to finish.
5. Open your site link and put it in the README.

Your URL usually looks like this:

```text
https://YOUR-USERNAME.github.io/YOUR-REPO/
```

Before you share it, click your links and make sure your images load.
