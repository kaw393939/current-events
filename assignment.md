# Quick Assignment Checklist

Make a small Markdown project using the steps we practiced in class. **Pass / fail.**

- [ ] Codex works in VS Code.
- [ ] GitHub SSH works.
- [ ] You cloned your repo with SSH.
- [ ] You used file commands to create and organize `README.md`, two Markdown pages, `images/`, and `notes/process.md`.
- [ ] You used Codex to make text, images, and page updates.
- [ ] Both Markdown pages have a title, image alt text, and Mermaid diagram.
- [ ] Your README links to both Markdown pages, and you checked the links and images on GitHub.
- [ ] You made two commits.
- [ ] You used `git stash` once.
- [ ] You pushed your work to GitHub.
